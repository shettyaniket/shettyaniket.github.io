ScatteredBrain — Privacy Policy

Last updated: 24 August 2026

The short version

ScatteredBrain collects no personal data. There are no accounts, no analytics, no ads, and no third-party tracking or crash-reporting SDKs. Nothing you enter ever leaves your device.

Your data stays on your device

All tasks, contacts, notes, activity log entries, wins, and waiting-on items are stored locally using Apple's SwiftData framework on your iPhone. This data is not synced to any server, not shared with any third party, and not accessible to me.

Backups

ScatteredBrain lets you export a backup as a JSON file from Settings → Backup. This file is generated entirely on your device and saved wherever you choose (Files, iCloud Drive, AirDrop, etc.). The app never sends this file anywhere automatically.

API keys

If you choose to use a cloud AI provider for the AI Add feature (Gemini, OpenAI, or Claude), you supply your own API key. That key is stored in your device's Keychain — not in the app's database, and not included in backups. It is used only to make requests directly from your device to the provider you chose; ScatteredBrain never sees or stores the key or the request content.

AI Add feature

When you type a task description in AI Add, ScatteredBrain first attempts to parse it entirely on-device using built-in natural language processing. If you have configured a cloud provider and on-device parsing is insufficient, the task description text is sent directly from your device to that provider's API using your own key. This text is not logged, retained, or linked to your identity by ScatteredBrain.

Children's privacy

ScatteredBrain does not knowingly collect data from anyone, including children under 13.

Third-party services

ScatteredBrain does not integrate any advertising networks, analytics platforms, or tracking SDKs of any kind.

Changes to this policy

If this policy changes, the updated version will appear on this page with a new date above.
